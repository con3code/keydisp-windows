# Windows 実機テスト チェックリスト

macOS/CI では検証できない項目の蓄積。**上から優先順** (フック基盤が最優先 — ここが崩れると全部やり直しになる)。
各フェーズの実装時に追記していくこと。

## A. フック基盤 (Phase 2) — 最優先

- [ ] WH_KEYBOARD_LL でキーが取れる (通常キー / 修飾キー / メディアキー)
- [ ] 押しっぱなしリピートの自前合成が正しい (pressedKeys 方式)
- [ ] 高速タイピングで取りこぼし・行化けがない
- [ ] フックタイムアウト → watchdog による再インストールが機能する (重負荷時)
- [ ] スリープ復帰・セッションロック解除後もキーが取れる
- [ ] 管理者昇格アプリにフォーカス中はキーが取れない (UIPI) — 想定どおりの挙動として確認
- [ ] UAC ダイアログ (Secure Desktop) 中に状態が壊れない (reconcile で回復)
- [ ] トレイアイコン表示・メニュー・explorer.exe 再起動後の再登録 (TaskbarCreated)
- [ ] RegisterHotKey が発火する / 他アプリと衝突しない既定を確認

## B. オーバーレイ (Phase 2-3)

- [ ] 透明・クリック透過 (下のアプリを普通に操作できる)
- [ ] TOPMOST が維持される (他の topmost アプリ、全画面動画、PowerPoint スライドショー上)
- [ ] 排他フルスクリーンのゲーム上での挙動確認 (表示されない場合は既知の制約として文書化)
- [ ] 行なし時に Hide → 新規行で再表示・TOPMOST 再主張
- [ ] 描画負荷: 4 行×長いコンボ連打で CPU/GPU が許容範囲か
- [ ] 見た目係数の調整 (OverlayConstants.cs): rowHeight / keycap 寸法 / フォント

## C. マルチモニタ・DPI (Phase 4)

- [ ] DPI 混在 (100%+150% 等) でオーバーレイの位置・サイズが正しい
- [ ] モニタ抜き差しでプロファイルが維持される (monitorDevicePath の安定性)
- [ ] カーソル画面追従・画面またぎドラッグでのプロファイル切替
- [ ] 中心スナップとガイド線の表示

## D. IME・日本語 (Phase 5)

- [ ] ImmGetOpenStatus による日本語入力モード判定 (MS-IME / Google 日本語入力 / ATOK)
- [ ] JIS かな配列表示の全キー確認 (゛゜「」の位置)
- [ ] 半角全角・無変換・変換・カタカナひらがなキーの表示
- [ ] ToUnicodeEx がキーボード状態を壊さない (フラグ 0x4、デッドキーのあるレイアウトでも)

## E. 周辺機能 (Phase 5)

- [ ] マウスハイライトの追従・左右の見た目差
- [ ] ホットエッジ下端とタスクバー(自動非表示含む)の競合確認
- [ ] 自動起動 (HKCU Run) の登録・解除
- [ ] 設定 json の保存・復元・破損時のフォールバック

## F. 配布 (Phase 6)

- [ ] zip 展開 → 実行 (SmartScreen の挙動確認、「詳細情報」→実行)
- [ ] self-contained 単一 exe が .NET 未導入マシンで動く
- [ ] Windows Defender 誤検知の有無 (低レベルフックを使うため要確認)
- [ ] x64 実機 + (可能なら) ARM64 Windows での動作
