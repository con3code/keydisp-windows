macOS/CI では検証できない項目の蓄積。**上から優先順** (フック基盤が最優先 — ここが崩れると全部やり直しになる)。
各フェーズの実装時に追記していくこと。

検証記録: ✅VM = Parallels 仮想環境で確認 (2026-08-18、MVP 8e53d74 / Phase3 b2d12a2)。実機での再確認は任意。

Phase 3 (b2d12a2) の VM 確認結果:
